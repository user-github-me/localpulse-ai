## Feature coverage

- Page reading, local/cloud routing, long-source retrieval and multi-tab/document questions.
- Explicit cloud consent, site/provider consent, never-send sites, Local-only mode changes during
  consent, redaction and omission of earlier private/unknown imported answers.
- Selection rewriting/proofreading, line breaks and refusal to replace a changed input.
- PDF files, YouTube transcript fixtures, GitHub readers, checked quotations and local excerpts.
- Searchable action library, persistent pins, custom prompts and empty toolbar recovery.
- History search beyond 100 conversations, favorites/rename, Markdown/JSON export/import,
  validation of malicious imports, provenance and confirmation before deletion.
- Temporary workspace capture/selection, original-source retry, all-or-nothing file validation
  and new cloud consent when saved collections are reopened.
- Local research save/reopen/search/export/delete, and verified source-context navigation.
- Interactive flashcards, missed-card review, local exports and malformed-output fallback.
- Installed-voice controls and cancellation; no remote voice fallback.
- Local follow-ups, editing/snoozing/completion, persistence, capacity and calendar export.
- Tab duplicate preview, close confirmation, saved session restoration and unit-tested grouping
  and pinned/changed-tab protection.
- OCR/audio opt-in download disclosures, real recognition/transcription, review and cache reuse.
- Explicit typed-query research and selected public source fetching, with no automatic private
  context in search requests.
- Tracking onboarding skip/retry/enable, unique Gmail/Outlook draft images, per-draft toggles,
  owner-image blocking, local read badges, private names, diagnostics and encrypted backup restore.
- Notifications require opt-in and permission, contain generic counts, coalesce concurrent
  collection and avoid notifying again for existing counts. These notification checks use API
  fixtures; an actual operating-system notification display was not manually verified.
- Accessibility checks in light/dark themes, narrow-panel layout, RTL output and platform or
  unassigned shortcut hints.

## Fixes discovered during verification

Production startup previously accessed the optional alarm API before it existed, preventing
welcome and toolbar handlers from registering. The e2e build's pre-granted permissions hid this.
Initialization now guards optional APIs, attaches the alarm listener after permission is granted
and includes a separate production-manifest regression test.

Media dialog effects now reset the mounted state during setup, retaining a successfully prepared
model across React effect cleanup. Shortcut hints now explain toolbar access when the extension
command has no binding. Issues [#14](https://github.com/user-github-me/localpulse-ai/issues/14) and
[#15](https://github.com/user-github-me/localpulse-ai/issues/15) document these fixes.

## Remaining verification limits

Gmail/Outlook tests use synthetic structural fixtures, not authenticated personal inboxes.
Providers can change compose/header structures. Proxies, preloads, caching and blocked images
make read counts estimates and can suppress later opens. Free hosting/queue limits remain.

Provider protocol and consent tests use fixtures; live credentials for every listed cloud service
and the browser's built-in AI were not supplied. Firefox was built and statically validated,
not exercised in a real Firefox profile. Windows/Linux shortcut rendering uses browser-platform
fixtures; those operating systems were not run here.

Mozilla's warnings include fallback Function constructors and dynamic import/DOM operations in
bundled dependencies. Runtimes are bundled and Chrome real-model tests succeeded under the
production-style CSP; that does not guarantee store acceptance or replace security review.
Audio is English-only and browser-codec dependent; cancellation completes at inference chunk
boundaries. Cached model data stays local until cleared. Browser-store review/publication and
merging PR #11 remain separate steps.
