# Code of conduct

LocalPulse follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, welcome newcomers, and focus criticism on
ideas rather than people. Harassment, insults and personal attacks aren't tolerated, in issues,
pull requests or any other project space.

Report unacceptable behavior privately to the maintainers through GitHub's report feature on the
relevant issue, pull request or discussion. Maintainers will review every report, keep it
confidential, and may warn or remove participants who break these rules.
